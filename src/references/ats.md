# Reference Manual: ATS Compatibility (ATS 解析合规手册)

---

## 1. ATS 友好性标准

ATS（Applicant Tracking System，求职者追踪系统）在筛选简历时依赖确定性的文本流与标准的标头层次。

### 核心合规法则：
1. **纯文本可提取性**：所有关键文字（姓名、公司、职位、技能词）必须是标准 HTML 文本节点，严禁使用图片代替文字。
2. **标准标头词典**：模块标题必须使用行业标准词汇：
   - `工作经历` / `Work Experience`
   - `项目经历` / `Projects`
   - `专业技能` / `Skills`
   - `教育背景` / `Education`
3. **线性文档流**：在双栏或复杂布局中，必须保证 DOM 树的逻辑顺序清晰，避免文字抽取时产生词句乱序。
4. **标准联系方式格式**：电话使用标准连字符或空格（如 `138-0000-0000`），邮箱使用标准格式。
