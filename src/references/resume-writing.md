# Reference Manual: Resume Writing & FAB Formula (简历撰写与论据模型)

---

## 1. FAB 论据构造法

优质的简历 Bullet 应当同时满足**技术深度**与**业务成效**，标准句式结构如下：

$$\text{Bullet} = [\text{强动词}] + [\text{Feature: 核心系统/项目}] + [\text{Advantage: 技术亮点/架构选型}] + [\text{Benefit: 量化业务/技术成效}]$$

### 范例对比：

- ❌ **弱表达（平铺直叙，无亮点）**：
  > "负责公司 AI 客服系统的后端开发，使用 Python 和大模型编写接口，处理客户问题。"
- ✅ **强表达（FAB 量化，证据充分）**：
  > "主导研发基于多 Agent 协同的企业级智能客服系统，采用 LangGraph 状态机与动态剪枝机制优化任务流转，将复杂多轮问答意图识别准确率提升至 94.2%，支撑日均 20 万+ 咨询请求并缩减 Token 成本 35%。"

---

## 2. 经历重塑的四大要素

1. **动词要强**：采用精准主动动词（主导、设计、架构、研发、解耦、优化、压榨）。
2. **技术要硬**：点出关键选型与技术方案（如异步流式响应、分库分表、双路召回、GC 调优）。
3. **指标要真**：数字可涵盖性能（Latency / QPS）、业务（转化率 / GMV）、稳定性（Crash 率 / SLA）、研发效能（构建提速 / 交付周期）。
4. **篇幅要精**：单条 Bullet 长度控制在 1~2 行（约 50~100 字），信息密度最大化。
