# Workflow 4: Position (优势对齐与策略设计)

> **目标：进行差距分析，将真实证据精准对齐 JD 需求，制定本轮简历策略。**

---

## 1. 策略制定四步法

1. **差距分析 (Gap Analysis)**：
   - **强匹配区 (Strong Match)**：候选人拥有 L1 强证据且完全契合 JD 必备项（重点大篇幅展开）。
   - **潜在匹配区 (Potential Match)**：候选人拥有 L2/L3 证据可迁移关联（合理呼应）。
   - **缺失区 (Gap)**：真实经历中未涉及的技能（严禁造假，弱化或引导用户补充真实经历）。
2. **确定模块优先级 (Section Priority)**：
   - 技术研发类：`Skills` ➔ `Projects` ➔ `Experience` ➔ `Education`
   - 管理架构类：`Summary` ➔ `Experience` ➔ `Projects` ➔ `Skills` ➔ `Education`
3. **确定高亮关键词清单 (Highlight Targets)**：
   - 提取 8~12 个高频硬核技术词，在 HTML 修改场中注入 `<strong>` 或标签。
4. **运用 FAB 模型重塑 Bullets**：
   - 确保每个经历条目包含：强动词 + Feature（系统） + Advantage（架构创新） + Benefit（量化成效）。
