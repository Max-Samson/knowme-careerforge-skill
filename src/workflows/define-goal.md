# Workflow 2: Define Goal (明确方向与定位)

> **目标：明确目标岗位、期望职级与核心价值主张，确立职业叙事重心。**

---

## 1. 目标设定要素

1. **目标岗位名称 (Target Role Title)**：
   - 明确标准岗位名称（如“资深 AI Agent 研发工程师”、“全栈架构师”）。
2. **期望职级 (Target Seniority)**：
   - 确定表达重心（Junior/Mid/Senior/Lead/Architect/Director）。
3. **行业细分领域 (Industry Domain)**：
   - 锁定行业背景（AI/大模型、企业级 SaaS、金融科技、消费互联网等）。
4. **核心价值主张 (Core Value Proposition - CVP)**：
   - 提炼一句话核心定位（15~25 字），概括候选人独特的技术与业务壁垒。
