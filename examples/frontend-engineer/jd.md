# Target Job Description: 资深前端架构师 / Web 全栈负责人

## 岗位职责
1. 负责核心 Web 应用、低代码平台与组件库的前端架构设计与演进；
2. 主导大型 SPA 应用的首屏性能调优 (FCP, LCP, INP) 与内存泄漏治理；
3. 推动 Monorepo 工程化、CI/CD 自动化部署及单元测试覆盖率；
4. 指导初中级前端工程师，主导团队技术规范与代码审查。

## 任职要求
1. 5 年以上 Web 前端研发经验，精通 TypeScript、React / Vue3 及其底层原理；
2. 熟练掌握 Next.js / SSR 架构、Node.js 服务端渲染及微前端体系；
3. 具备深厚的前端性能优化功底与复杂状态管理经验 (Zustand / Redux)；
4. 具备良好的工程化视野与跨端（Electron / Taro）开发能力者优先。
