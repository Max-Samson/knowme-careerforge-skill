# Target Job Description: 资深 AI Agent / LLM 应用架构师

## 岗位职责
1. 主导企业级多 Agent 智能协同中台的架构设计与核心研发，支撑复杂商业业务流转；
2. 负责 RAG 检索增强生成流水线的深度优化（多路召回、重排序、Chunk 切分与向量混合检索）；
3. 负责大模型 Prompt 动态管理、Token 降本与推理延迟压测；
4. 探索基于开源大模型（Llama, DeepSeek）的微调（Fine-Tuning）与评估 Benchmark 搭建。

## 任职要求
1. 计算机相关专业本科以上学历，3 年以上大模型应用或自然语言处理研发经验；
2. 精通 Python、FastAPI、Asyncio 高并发编程；
3. 深度掌握 LangGraph / LangChain / LlamaIndex 等 Agent 工作流框架；
4. 熟练掌握 Qdrant / Milvus 等向量数据库的原理与性能调优；
5. 具备 Docker、Kubernetes 云原生与微服务落地实战经验。
