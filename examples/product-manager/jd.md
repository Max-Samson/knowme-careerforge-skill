# Target Job Description: 资深 AI 产品经理 / 创新业务负责人

## 岗位职责
1. 主导 AI 驱动的垂直行业 Agent 产品的 0 到 1 需求规划、商业化落地与版本迭代；
2. 深度挖掘企业用户业务痛点，产出高保真 PRD、交互原型与业务闭环流程；
3. 协同算法与工程团队，评估大模型技术边界，驱动 Prompt 与知识库工作流调优；
4. 负责产品数据监控与转化漏斗优化 (A/B Test)，对产品 DAU、ARR 与续费率负责。

## 任职要求
1. 3 年以上互联网或企业级软件产品经验，具备大模型 / Agent 产品落地实战者优先；
2. 具备出色的跨部门沟通领导力与敏捷项目推进能力；
3. 具备严密的数据分析功底与商业敏锐度；
4. 计算机、数学或人机交互相关专业背景优先。
