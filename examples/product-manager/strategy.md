# Resume Strategy: AI Product Manager

## 1. 核心定位 (Value Proposition)
> 复合型 AI 产品专家，兼具技术洞察与商业闭环能力，曾主导企业级智能助手从 0-1 商业化，为企业带来千万级 ARR 增长。

## 2. 模块排序与权重
1. **核心价值概述 (Summary)**：置顶突出 0-1 商业化能力与跨部门协同。
2. **工作经历 (Experience)**：重点展示产品上线、用户留存提升 35% 与业务增收。
3. **重大项目 (Projects)**：展示企业级智能工单分发系统与 PLG 增长实验。
4. **核心能力与工具 (Skills)**：PRD 产出, A/B Testing, Prompt 工程, SQL 数据分析。

## 3. 选定模板
- **模板 ID**：`executive` (Executive Modern Split)
- **色系**：深空板岩灰 (`#1e293b`) + 沉稳松石绿 (`#0f766e`)
- **目标页数**：1~2 页
