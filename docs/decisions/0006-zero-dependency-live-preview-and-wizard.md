# ADR-0006: 零依赖本地实时热重载预览与对话式建档向导

## 状态
已通过 (Accepted)

## 背景与上下文
在用户使用 KnowMe CareerForge Skill 或 CLI 终端时，存在两个直接影响使用体验的核心诉求：
1. **即时可视化反馈**：候选人与开发者希望在生成或修改简历时，能够直接在本地浏览器中观察 A4 渲染效果，并在 Token 或内容修改时实现秒级无缝热重载；
2. **非代码仓场景下的顺畅建档 (Mode D)**：许多用户初次使用时只输入了一句简略的自然语言（如：“帮我写一份资深前端简历，我有5年低代码开发经验”）。若缺少结构化的交互引导向导，容易出现冷启动卡顿或信息缺失。

我们对引入重型前端开发服务器（如 Vite、Next.js、Webpack）与使用轻量原生服务进行了技术权衡。

## 架构决断
我们决定采用以下两项轻量化方案：
1. **零依赖实时热重载预览服务器 (`knowme preview` / `knowme serve`)**：
   - 基于 Python 原生标准库 (`http.server`) 或 Node.js (`http`) 构建，**零引入第三方运行时依赖**，启动耗时 $<50\text{ms}$；
   - 服务端拦截响应流，向 HTML 动态注入 25 行轻量级 Server-Sent Events (SSE) / 轮询监听脚本，监听 `workspace/resume.html` 的文件更新；
   - 服务启动后自动调用系统默认浏览器打开 `http://localhost:4173`。
2. **对话式建档向导与渐进式采集协议 (`knowme wizard` / Agent Mode D 协议)**：
   - CLI 提供优雅的分步交互式终端向导；
   - Agent Skill 端确立渐进式 3 轮建档对话（第 1 轮：基本信息与求职目标 ➔ 第 2 轮：核心经历与职责 ➔ 第 3 轮：代表性项目与 FAB 量化成果）；
   - 采集完成后自动组装为标准的 `workspace/evidence-master.json`。

## 影响与收益
### 正向收益
- **开箱即用的所见即所得体验**：用户无需安装庞大的 npm 依赖即可在本地浏览器获得类似现代 Web 开发的热重载体验；
- **全平台体验一致性**：无论用户是通过终端命令行（CLI）还是在 Claude Code / Cursor / Windsurf 等对话式 AI 编程助手中使用，均能获得标准统一的交互流程与视觉交付物。
