# ADR-0005: 页面自愈闭环的启发式 Design Token 自动调优算法

## 状态
已通过 (Accepted)

## 背景与上下文
在 KnowMe CareerForge 中，由于候选人经历的丰富度与资历深浅差异较大，实例化装配到 `workspace/resume.html` 的内容长度不尽相同。初始渲染时，DOM 的物理高度可能会超出 A4 标准页面边界（单页上限为 $1122.5\text{px}$ @ 96 DPI，双页上限为 $2245\text{px}$）。

在此之前，当 `validate-resume.py` 质检报告提示高度溢出（例如 `+18px`）时，AI Agent 需要在多轮对话中手动猜测并修改 CSS 变量值。这种方式带来了以下问题：
1. **多轮往返与 Token 消耗**：Agent 需要多次调用工具重试，导致响应延迟增加；
2. **步长随意与缺乏规范**：手动调参容易填入随意的浮点像素值，破坏了底层 2pt 间距阶梯的设计规范；
3. **字号过小风险**：缺少物理保护底线，可能将正文字号缩得过小（如低于 8.5pt），导致打印时文字辨识度下降。

## 架构决断
我们在 `scripts/validation/validate-resume.py` 中内置 **启发式 Token 自动自愈收敛算法 (`--auto-heal`)**，并在一键装配管线 `scripts/pipeline/forge.py` 中无缝集成：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       启发式 Token 自动自愈收敛算法流程                       │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. 通过无头浏览器引擎精确测量当前 DOM 物理高度 (H_actual 与 H_target 比较)    │
│    若 H_actual <= H_target (完美容纳)：直接返回 PASS (0 次迭代)              │
│                                                                             │
│ 2. 计算溢出差值：ΔH = H_actual - H_target                                    │
│                                                                             │
│ 3. 优先级梯阶式参数自动收缩校准：                                            │
│    ├── 第一阶 (模块间距 Section Spacing):                                   │
│    │   --resume-space-section: 12pt ➔ 10.5pt ➔ 9.5pt ➔ 8.5pt                 │
│    ├── 第二阶 (条目与列表间距 Item & Bullet Spacing):                        │
│    │   --resume-space-item:    8pt  ➔ 7pt    ➔ 6pt   ➔ 5pt                  │
│    │   --resume-space-bullet:  3pt  ➔ 2.5pt  ➔ 2pt   ➔ 1.5pt                │
│    └── 第三阶 (排版缩放与行高 Typography Scale & Line Height):               │
│        --resume-font-size-body:   9.2pt ➔ 9.0pt ➔ 8.8pt (物理安全底线)       │
│        --resume-line-height-body: 1.45  ➔ 1.40  ➔ 1.38                      │
│                                                                             │
│ 4. 每一步调整后重新测量 DOM 高度，一旦达到 100% Fit 即刻退出并保存。         │
│                                                                             │
│ 5. 若耗尽一至三阶后仍存在 ΔH > 0 溢出：                                      │
│    输出精准的内容精简指引（包含具体超标字符数与对应 DOM 节点的 CSS 选择器），  │
│    交由 AI Agent 进行针对性的语义提炼与精简。                                │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 约束与防护边界
1. **物理字号安全底线**：`--resume-font-size-body` 绝对不允许低于 `8.8pt` (`11.7px`)，确保 A4 纸张打印后的肉眼可读性；
2. **对齐间距阶梯标准**：所有微调后的间距数值必须严格对齐 `--primitive-space-*` 的标准倍数（以 0.5pt 或 1pt 为最小离散步长）；
3. **单文件内联修改**：自愈器直接对 `workspace/resume.html` 中的 `:root { ... }` 变量块进行更新，不引入任何外部依赖。

## 影响与收益
### 正向收益
- **秒级自动收敛**：90% 以上的常见轻微溢出（$+5\text{px} \sim +40\text{px}$）可在单次运行中于 $<0.5$ 秒内自动收敛，彻底省去 Agent 的多轮试错成本；
- **排版比例和谐**：保证字号、行高与各级间距按比例协调收紧，避免版面失衡；
- **精准移交语义提炼**：当文本量确实超出物理单页极限时，输出精准的选择器与超标量，辅助 Agent 进行高质量的文字提炼。
